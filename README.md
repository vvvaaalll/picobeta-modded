# PicoBeta

PicoBeta is a highly optimized Minecraft Beta server designed primarily to run on a Raspberry Pi Pico. It uses around 30 MB of RAM.

# PicoBeta-Modded

PicoBeta-Modded is a Minecraft Beta 1.7.3 server focused on creating lightweight server software that can be implemented across different programming languages and hardware.

The project contains multiple implementations and experiments, including **Python and C++**, with the goal of exploring different ways to recreate and improve a Beta 1.7.3 server.

## Features

* Minecraft Beta 1.7.3 support
* Protocol 14
* Lightweight server design
* Multiple implementations
* Support for different programming languages and hardware
* Easy to experiment with and modify

PicoBeta-Modded is still in development, so features and implementations may change over time.

## Inspiration

The project was inspired by the original [PicoBeta project](https://github.com/OfficialPixelBrush/PicoBeta), with a focus on keeping classic Minecraft multiplayer lightweight and accessible.
