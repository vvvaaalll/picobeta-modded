# PicoBeta-modded

PicoBeta-modded is an experimental Minecraft Beta 1.7.3 server project focused on creating a lightweight and simple server software for the classic Minecraft Beta experience.

The project contains multiple implementations and experiments, including **Python and C++**, with the goal of exploring different ways to recreate and improve a Beta 1.7.3 server.

## Features

* Minecraft Beta 1.7.3 support
* Protocol 14
* Lightweight server design
* Multiple implementations
* Easy to experiment with and modify

PicoBeta-modded is still in development, so features and implementations may change over time.

## Inspiration

The project was inspired by the original PicoBeta projects https://github.com/OfficialPixelBrush/PicoBeta , with a focus on keeping classic Minecraft multiplayer lightweight and accessible.
